# 你好，我是 ThinkPair 👋

以前做过一线销售，也负责过门店、区域经营和组织人力工作。现在在做「降噪实验室」，也在用 AI 做产品、整理知识。

我关心一门生意怎么运转，也关心一个人怎样把自己的经验和本事，做成别人真正用得上的东西。这也是我做内容和尝试新产品时，常常会想的问题。

这个 GitHub 放我在经营、学习、研究和内容创作中做出来的项目和方法。能公开的代码、笔记、模板和知识库，会陆续整理在这里。

## 做过和正在做的东西

- **[降噪星图](https://github.com/ZHY999999999/jiangzao-xingtu-open-source)**：我整理的公司和行业知识库。从“这家公司是做什么的、靠什么赚钱”开始，边学边补。
- **[一人成校](https://study.thinkpair.cn/)**：正在做的学习工具，把资料、针对练习和复测接起来，供老师和家长使用。目前受邀试用中，尚未开源。
- **[AI 项目接手模板](https://github.com/ZHY999999999/thinkpair-starter-kit)**：几页简单的模板，记下项目做到哪儿、下一步做什么。换个 AI 对话继续干活时，少从头解释几遍。

有用就拿去试试；哪里不好用，也欢迎在对应项目里直接告诉我。
